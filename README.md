# Contact Book Application (Java)

A simple console-based Contact Book application developed in Java.  
This project demonstrates core Object-Oriented Programming (OOP) concepts and file handling.

---

## Features
- Add new contacts
- Display all contacts
- Search contacts by name
- Update contact details
- Delete contacts
- Persistent storage using a text file

---

## OOP Concepts Used
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- File Handling

---

## Technologies
- Java (JDK 8 or higher)

---

## How to Run

```bash
javac Main.java
java Main
